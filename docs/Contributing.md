# Contributing

Thank you for contributing to PortFootprint!

## Code Quality Standards
To maintain production-grade quality, all contributions must conform to the following standards:

1. **PEP 8 Compliance**: Code must pass all Ruff formatting checks.
2. **Type Annotations**: All public classes, functions, and parameters must contain explicit type annotations.
3. **Docstring Coverage**: All public classes and modules must contain clear, descriptive docstrings.
4. **Unit Tests**: Pull requests must include testing coverage for the introduced changes.
5. **Static Analysis Checkers**: Code must compile and run cleanly under Ruff, MyPy, and Bandit checks.

## Pull Request Checklist
- [ ] Run Ruff checks and formatting scripts.
- [ ] Verify MyPy types pass strictly.
- [ ] Run Bandit to check for security vulnerabilities.
- [ ] Run Pytest to verify 100% of test cases pass successfully.
