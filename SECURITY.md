# Security Policy

## Supported Versions

We actively support and fix security issues in the following versions of PortFootprint:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please do not disclose it publicly. We ask that you report it responsibly to give developers time to implement fixes.

Please send vulnerability reports via email to: `security@example.com` (or submit a private advisory on GitHub).

Include the following details in your report:
* A description of the vulnerability and its potential impact.
* Steps to reproduce the issue, including target configuration payloads.
* Your contact information if you would like to be credited for discovery.

We will acknowledge receipt of your vulnerability report within 48 hours and work with you to release a coordinated security update.
